# null;limit

null;limit (nulllimit.gg) is a build studio run by Vitoshi (Ryan Watkins). It builds software end to end — scoped, shipped, and supported. The site is a single page: what we do, how we work, and a build request form. There is no published pricing; every build is scoped individually.

---

## What we do

1. Software development — custom systems, end to end
2. App builds — iOS, Android, web; design to App Store
3. Database builds — schema, migrations, integrity, scale
4. AI systems & agents — automation that runs your operations
5. Marketing campaigns — strategy through execution
6. Email campaigns — Klaviyo builds, flows, automation

Certifications: Anthropic certified · Klaviyo certified

---

## How we work

1. Scope — "done" is defined before anything gets built
2. Build — working software early and often
3. Beta — a real, usable version in your hands
4. Market-ready — the finished product, against a signed acceptance checklist
